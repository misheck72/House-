# Aurelia International School — Production Static Multi-Page Site

A premium static school website built from the supplied design brief.

## Pages
Home, Academics, Programs, six program detail pages, Campus/Virtual Tour, Student Life, Faculty & Leadership, News, Events, Gallery, Admissions, FAQ, Contact and 404.

## Run
Use any static server, for example `npx serve .`.

## Before launch
- Replace fictional school content, names, statistics, addresses and contact details.
- Replace external image URLs with approved school photography and local assets.
- Replace the Formspree placeholder endpoint on Contact.
- Replace sitemap domain.
- Add final favicon, OG image and analytics if required.
- Connect external admissions/application system.
- Replace demo event/news content with approved data.

The structure is intentionally static and content can later be moved into JSON/Markdown/MDX or a CMS without redesigning the UI.
